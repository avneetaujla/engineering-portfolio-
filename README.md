# Avneet Aujla | Mechanical Engineering Portfolio

Personal engineering portfolio for Avneet Aujla — Mechanical Engineering, University of Guelph.

## Stack

- React + TypeScript
- Vite
- Tailwind CSS v4
- React Router
- Lucide icons

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Manual configuration

1. Set email in `src/data/site.ts` (`contact.email`) when ready
2. Replace project placeholders in `src/data/projects.ts` with approved copy and assets
3. Add images under `public/` and set `media[].src` on each project

LinkedIn and resume are already configured.


## Project data

All projects live in `src/data/projects.ts`. Add a new project object there; cards and case-study routes update automatically.
